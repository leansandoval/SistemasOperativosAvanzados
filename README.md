<a id="herramientas-utilizadas"></a>
## 🛠️ Herramientas Utilizadas
* **Arduino IDE / C++**: Entorno de desarrollo y lenguaje utilizado para programar el firmware de la placa de desarrollo Smart Saw (sensores, actuadores y lógica en tiempo real).
* **Android Studio / Kotlin**: IDE y lenguaje empleado para construir la aplicación móvil encargada del monitoreo y control remoto del sistema.
* **FreeRTOS**: Sistema operativo de tiempo real utilizado para la gestión multitarea, colas de mensajes y priorización de hilos en los microcontroladores.
* **MQTT / Bluetooth / Wi-Fi**: Protocolos de red y conectividad implementados para la transmisión en tiempo real de datos entre el hardware embebido y la app móvil.
* **Sensórica & Actuadores**: Integración de componentes físicos (sensores de velocidad, corriente, presencia y actuadores de corte) en la sierra inteligente.
* **Visual Studio Code**: Entorno alternativo para la edición de scripts, configuración de entornos y documentación del proyecto.
